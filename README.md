# Registo de Despesas

Aplicação web para registar despesas pessoais por categoria (desafio técnico).
Estado atual: base de dados feita; API e frontend por fazer.

## Como correr

1. Ter o Docker Desktop aberto.
2. Na raiz do projeto: `docker compose up -d`
3. A BD fica disponível em `localhost:5433` (utilizador `postgres`).
4. Correr `db/schema.sql` na BD (por agora manualmente, via pgAdmin).
